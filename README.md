# SANGRAM AI — Different Minds. One Arena.

A premium multi-model **AI debate arena** frontend. Pick two AI model profiles,
pose one question, watch a four-round adversarial debate stream through a
shared timeline, and receive a single synthesized final answer.

> **Prototype status:** frontend only. Battles are generated by a
> deterministic local simulation engine — no provider APIs are connected and
> no API keys exist in this repo. The UI states this plainly as
> `Demo Mode · Simulated responses`.

## Project Structure

All application source code, components, styles, documentation, and assets are inside the `frontend/` folder:

```text
sangram-ai/
├── frontend/                     # Complete Vite + React frontend application
│   ├── src/
│   │   ├── components/           # UI components (Navbar, Landing, Arena, Config, etc.)
│   │   ├── data/                 # Model roster & cognitive archetypes
│   │   ├── services/             # Deterministic engine, stream runner, history, share
│   │   ├── styles/               # Design tokens (global.css)
│   │   ├── App.jsx               # Main state machine
│   │   ├── App.css               # Component & motion styles
│   │   └── main.jsx              # React DOM entry
│   ├── public/                   # Static assets (logo, favicon)
│   ├── docs/                     # Backend contracts & architecture documentation
│   ├── index.html                # Entry HTML
│   ├── vite.config.js            # Vite configuration
│   └── package.json              # Frontend dependencies
└── README.md                     # Project overview
```

## Run Locally

```bash
# 1. Navigate to the frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview the production build
npm run preview
```
